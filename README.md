# YouTube Clone 📺

A simple YouTube clone webpage created using **HTML and CSS**. This project recreates the basic visual layout of YouTube with a navigation bar, sidebar, video thumbnails, icons, and hover effects.

## ✨ Features

* YouTube-style navigation bar
* Sidebar navigation
* Video thumbnail layout
* Icons
* Hover effects
* YouTube-inspired user interface
* Clean HTML and CSS structure

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure


Youtube_clone/
├── index.html
├── style.css
└── assets/


## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation or setup is required.
